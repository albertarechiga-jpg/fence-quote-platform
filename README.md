# Fence Quote Prototype

Open `index.html` in a browser or serve it as a static site. Includes four fence style options, local JPG/PNG/WebP image preview, fence measurements, validated quote-request form, and downloadable JSON sample lead.

**Demo only:** No backend, AI photo identification, server-side image upload, contractor delivery, or real price estimation. No customer information is transmitted. The upload is previewed in-browser, and the quote request downloads to the user's device.
